## Changes since v0.23.0

**Deletion behavior changed.** **Delete item with data** now removes the entire app folder, including settings and unrelated files inside it. For a local file, that means its containing folder. Review the path in the confirmation dialog. Choose **Delete item** to remove just the app list entry.

- **Updating apps.** In the desktop app, use **Get updates** for one item or **Update all items** for the whole app list. These replace the separate check-only commands. Batch updates retry failed items after 1, 2, and 4 seconds. You can cancel during the wait.
- **Detecting installer versions.** Direct downloads can read a Windows executable’s file version, a Qt installer’s package version, or a version in the final download URL. ReleaseShelf also detects when a publisher replaces an installer with the same version but a new modification time. Publisher recipes can use `{asset}` in archive and extraction folder names to distinguish builds.
- **GitHub and MajorGeeks downloads.** GitHub branch ZIP entries switch to the latest published release when one becomes available and download the source at its tagged commit. MajorGeeks downloads follow the current mirror link.
- **Restoring settings after installation.** Items with a restore script or saved portable settings now restore them automatically after a successful installation. For portable executables, restoration runs when the app closes. You can turn this off per item or open its restore script in Notepad from the **General** tab.
- **Editing setup checklists.** Double-click a checklist to edit step names, descriptions, and PowerShell commands. **Save** stores the edits. Use **Apply selected** in the **Checklist** tab when you’re ready to run the selected steps.
- **Finding apps in the list.** Click a category icon in the collapsed sidebar to filter the list, hover to see its name, or use the arrows to reach more categories. App icons now support MSI packages, artwork inside ZIPs, cached Microsoft Store logos, and custom 16 × 16 PNGs.
